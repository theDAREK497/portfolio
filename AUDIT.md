## Проверки

- Полный прогон включает форматирование, ESLint, TypeScript, 16 автоматических тестов и production-сборку.
- Тесты проверяют обе локали, диалоги, просмотр изображений, фильтры, переключение темы, оглавление, прямое открытие русской статьи, HTML-метаданные, существование изображений и сохранность всех абзацев статьи.
- В браузере проверены desktop и мобильный первый экран, RU/EN, открытие кейса и переход к статье. На ширине 390 px горизонтального переполнения не обнаружено. На 320 px обнаружена и исправлена минимальная ширина body.
- `npm audit` и `npm audit --omit=dev`: известных уязвимостей не найдено на момент проверки. Это не полноценный аудит безопасности.

## Ограничения и следующий шаг

Из этой среды опубликованный GitHub Pages-адрес ответил тайм-аутом. Это не доказывает недоступность сайта для других посетителей. Проверки относятся к локальному исходному коду и production-сборке; публикация и индексация не подтверждены.

Изменения не отправлены в GitHub. После commit/push необходимо дождаться успешного workflow и проверить главную, обе версии статьи, оба резюме и sitemap на опубликованном адресе. Pages должен быть настроен на GitHub Actions.

Данные, которые по-прежнему должен подтвердить владелец: актуальность текущего места работы и доступности к найму; официальные переводы дипломов. Уровень английского B1 подтверждён владельцем 8 сентября 2026 года. Неподтверждённые показатели эффективности из `src/content/verification.ts` не добавлялись.

## Техническое обоснование

Предварительно доступный HTML и обычные адреса страниц соответствуют рекомендациям [Google по JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics): не все роботы выполняют JavaScript, а hash-маршруты ненадёжны для обнаружения отдельных страниц.

URL сборки берётся из документированного выхода `base_url` [configure-pages](https://github.com/actions/configure-pages/blob/main/action.yml). Используемые версии Pages Actions проверены по официальным релизам: [configure-pages v6](https://github.com/actions/configure-pages/releases/tag/v6.0.0), [upload-pages-artifact v5](https://github.com/actions/upload-pages-artifact/releases/tag/v5.0.0), [deploy-pages v5](https://github.com/actions/deploy-pages/releases/tag/v5.0.1).
